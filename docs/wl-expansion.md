# R08.1b — WL EXPANSION
Ten original sound engines and 30 factory patches. New instruments use the same track, preset, MIDI, offline render, export and project registry as existing instruments. No vendor code, samples or brand emulation. TITAN and KORA are plucked-string models; MBIRA and NGOMA are modal approximations, IMPERIAL and CHOIR are synthetic ensembles, not recorded orchestras/vocals. DRIFT loops a deterministic one-second overlap-add grain cloud; it does not yet load external samples. MATRIX has one carrier and two independent FM modulators. TONEWHEEL is additive, not a specific hardware emulation. New native parameter panels use existing host controls; dedicated graphics follow in R08.1c. CI verifies thirty dry patches and expands the prior full catalog render audit. Listening quality and performance with crowded arrangements remain to be validated. Depends on #170 if not yet merged.
