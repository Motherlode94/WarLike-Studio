# R08.2c — Native note expression
WL EXPANSION notes support optional relative bend up to ±12 semitones, vibrato up to 100 cents (fixed 5.5 Hz with onset ramp), and normal/staccato/tenuto gate. Bend rises over the final three quarters of the note. These are note-local editor parameters, not captured hardware pitch wheel or MPE messages. Oscillator detune and pitched PCM detune share the same curve; NGOMA's unpitched strike transient is intentionally unchanged. FM modulators receive the same pitch curve as the carrier. Live scheduling and offline render use the same voice path. Old notes without expression keep the previous behavior. No changes to third-party or other native instrument families. Unit and browser tests required before merge.
