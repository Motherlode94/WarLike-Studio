# R08.2a — Polyphonic instrument render gate
The existing 30-patch dry-note gate remains unchanged. The new gate renders 32 overlapping notes per instrument at 44.1 and 48 kHz, using the actual AudioEngine and factory patches, with an explicit -24 dB test bus. Reports finite samples, sample peak, RMS, clipping, DC, stereo difference and the last 100 ms RMS. Encodes and decodes 24-bit WAV for each case, checks the RIFF header and compares decoded PCM against original samples. No automatic gain adjustment to user tracks, no DSP changes, no claim of real-time performance or audible quality certification. Headroom is a test fixture, not a limiter. Reports are CI artifacts. Real arrangements and physical listening remain separate validation steps.
