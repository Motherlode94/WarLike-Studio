# VECTOR Suite — R06.4
Original vector hardware family: EQ 06 (19 controls), COMP 01 (7), LIMIT 03 (3).
All three retain native DSP and their own face. Master insert picker exposes VECTOR factory and personal presets; master modules use the same local user bank as track modules. Saving a master module preset does not save or replace the full mastering chain.
The dedicated browser gate verifies three simultaneous master inserts, ordered routing metadata, preset selection, local preset bank, portable save, screenshots in four themes and mobile. Existing DSP and export gates remain mandatory. LIMIT displays observed sample peaks, not certified true peak; EQ is a calculated frequency response; COMP displays its internal compressor reduction.
Manual listening, hardware and visual acceptance remain separate.
