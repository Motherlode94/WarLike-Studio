# R08.2b — Voice PCM cache
WL TITAN, KORA, DRIFT and NGOMA reuse deterministic mono PCM buffers per AudioContext. Cache keys include every PCM-producing parameter and pitch where relevant; each note still has independent sources, envelopes, filters and timing. LRU retains at most 32 entries and 16 MiB per context; active voices can retain evicted buffers until playback ends. Contexts are weakly referenced. No pitch, gain, preset or DSP algorithm changes. Cache metrics report hit/miss counts, not measured CPU savings. Existing polyphony and WAV gates remain enabled. Physical real-time performance is not certified.
